# Trust and payment badges

**File:** `sections/trust-badges.liquid`

A strip of payment and trust badges. No brand logos are bundled: you upload your own image files, or use text badges.

## Settings

Heading, alignment, image badge height, grayscale toggle, and a rich-text note.

## Blocks

- **Image badge**: image picker plus alt text. Upload logo files you are allowed to use.
- **Text badge**: a rounded text chip.

## Bangladeshi payment methods

Local methods work well as text badges, which avoids bundling third-party logos:

| Method | Suggested text badge |
| --- | --- |
| bKash | `bKash` |
| Nagad | `Nagad` |
| Rocket | `Rocket` |
| Cash on delivery | `Cash on Delivery` |
| Cards | `Visa / Mastercard` |

The default preset already contains `Cash on Delivery`, `bKash` and `Nagad` text badges. If you want logos, download the official assets from each provider's brand or merchant page and upload them as image badges. Only show methods your checkout actually accepts.
