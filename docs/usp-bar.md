# USP bar

**Files:** `sections/usp-bar.liquid`, `snippets/sk-icon.liquid`

A row of unique selling points (delivery, COD, returns, support). On mobile it is a horizontal scroll-snap strip; from 750px it becomes an even grid.

## Settings

Background color and text color.

## Blocks

**USP** (max 6): icon (delivery, shield, returns, support, tag, check, star, heart or none), title, text. Icons are inline SVG, so no icon font is loaded.

## Notes

Needs the `sections.usp.label` translation key (accessible name of the region).
